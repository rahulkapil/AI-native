# The AI Native Leader — HTML reader

Open index.html in a browser, or upload it to any static web host. The complete book, covers, styles and reading controls are contained in that file. No build step, account, network connection or external script is required.

Contents stay on the left on larger screens and open from the Contents button on phones. The reader offers text-size controls, paper/light/dark themes and a Continue reading button. Preferences and position are stored only in this browser when local storage is available. Printing hides the navigation and controls.
